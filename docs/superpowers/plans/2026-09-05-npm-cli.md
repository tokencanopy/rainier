# npm CLI distribution, beta 0.0.3

## Scope and acceptance

Publish `@tokencanopy/rainier@0.0.3` under npm's `beta` dist-tag. Support npx and
global installation on macOS/Linux, arm64/x64, without Go. Reuse the exact
v0.0.3 GitHub release binaries. No cloud/backend, Go CLI, authentication, or
session behavior changes. One implementation slice owns `npm/`, its test gate,
and install documentation.

## Design

A dependency-free Node.js 22+ launcher downloads lazily on explicit invocation.
This avoids lifecycle-script dependencies and works with `--ignore-scripts`.
Bundled platform packages would avoid a second download host but require five
coordinated npm publications; a single wrapper reuses the verified release.
Direct binary downloads remain available for users without Node.

Use fixed HTTPS release URLs and pinned archive plus binary SHA-256 hashes.
Bound downloads to 60 seconds, 16 MiB, and five redirects; reject HTTPS
downgrades. Extract only `rainier` using system tar, after archive verification.
Cache per version/platform/architecture, verify on reuse, repair corruption,
and atomically rename a verified file from a unique temporary directory.
Concurrent installs publish identical bytes, never partial executables.
This is a per-user cache, not a defense against compromise of that same OS user.

Run without a shell, inherit terminal streams, forward arguments and termination
signals, and preserve child exit status. No postinstall, telemetry, credentials,
auto-updater, or new native version flag. Cache/download failures fail closed
with a standalone-release fallback link. Proxy configuration and Windows
support are deferred. npm publishing authentication or a scope conflict is a
stop condition, not a reason to change package names silently.

## Verification

Node tests cover platform mapping, verified install/reuse/repair, corrupted
archives/binaries, concurrent installs, redirects/status/size/timeout failures,
literal arguments, exit codes and signals. Run the repository's full Go verify
gate. Pack an allowlisted tarball and exercise npx and global install with real
GitHub downloads, then verify the published registry tarball and fresh npx use.
Independent and adversarial read-only reviews precede npm publication.
